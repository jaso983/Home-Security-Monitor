# Family Faces Directory

Place front-facing photos of family members here for stranger identification.

## How to Add a Family Member

1. Add 1-3 clear, front-facing photos per person (JPG or PNG format)
2. Name each file with the person's name, e.g. `zhangsan.jpg`, `zhangsan_2.jpg`
3. Restart the application - face encodings will be cached automatically

## Tips

- Use well-lit, front-facing photos for best results
- Avoid photos with multiple faces
- Supported formats: .jpg, .jpeg, .png, .bmp
- The system uses OpenCV LBPH face recognition with a configurable tolerance threshold

# Home Security Monitor 系统实现说明

## 一、系统架构

系统采用**三层模块化架构**，自上而下分为：

```
┌─────────────────────────────────────────────────┐
│  表现层 (GUI/CLI)                                │
│  main_gui.py ─── SecurityApp (tkinter GUI)      │
│  src/main.py  ─── CLI (OpenCV窗口)              │
├─────────────────────────────────────────────────┤
│  业务逻辑层 (Core)                               │
│  alarm_manager.py  ─── 报警防抖去重              │
│  db_manager.py     ─── SQLite数据库CRUD          │
│  config.py         ─── 配置文件读取              │
│  logger.py         ─── 日志初始化                │
│  face_recognizer.py── 陌生人识别                 │
├─────────────────────────────────────────────────┤
│  模型层 (Models)                                 │
│  yolo_detector.py  ─── YOLO推理 (人员+火焰)     │
│  fire_model.pt     ─── 自训练火焰/烟雾模型       │
│  family_faces/     ─── 家庭成员照片库            │
├─────────────────────────────────────────────────┤
│  存储层                                          │
│  alarms.db (SQLite)  ─── 报警记录               │
│  screenshots/        ─── 报警截图               │
│  security_monitor.log── 运行日志               │
└─────────────────────────────────────────────────┘
```

## 二、入口与启动

**GUI模式**（主入口）：
```
run.bat → python main_gui.py → tkinter.Tk() → SecurityApp(root)
```
`main_gui.py` 仅做两件事：设置 `sys.path` 到 `src/`，创建 tkinter 根窗口并启动 `SecurityApp`。

**CLI模式**（调试入口）：
```
python src/main.py → OpenCV窗口循环
```

## 三、检测主循环（核心流程）

SecurityApp 启动后，`_detection_loop()` 以 30ms 间隔持续运行，每帧执行：

```
1. 摄像头读帧 → ret, frame = cap.read()
   ├─ 失败 → camera_ok=False, 显示占位图, 1秒后重试
   └─ 成功 → 继续

2. 判断布防时段 → _check_time_in_range(person_start, person_end)
   ├─ 在时段内 → YoloDetector.detect_person(frame)
   │   ├─ 检测到人 → FaceRecognizer.is_stranger(frame)
   │   │   ├─ 陌生人 → AlarmManager.should_trigger_alarm("person")
   │   │   │   └─ True → _save_alarm("person")  → 截图+写库
   │   │   └─ 家人 → 不报警，显示"Family"绿色状态
   │   └─ 未检测到人 → 继续
   └─ 不在时段 → 跳过人员检测

3. 全天候火焰检测 → YoloDetector.detect_fire(frame)
   ├─ 检测到火焰 → AlarmManager.should_trigger_alarm("fire")
   │   └─ True → _save_alarm("fire")  → 截图+写库
   └─ 未检测到 → 继续

4. 合成显示帧 → 时间戳 + 布防状态叠加文字

5. 更新界面 → video_panel, status_panel, history_panel
```

## 四、各模块实现详解

### 4.1 YoloDetector（`src/models/yolo_detector.py`）

两个独立的 YOLO 模型并行推理：

- **person_model**：`YOLO("yolov8n.pt")` — ultralytics 首次运行自动从缓存加载 COCO 预训练权重（6MB），检测 class 0 (person)，置信度阈值 0.8
- **fire_model**：`YOLO(fire_model_path)` — 自训练模型，classes=[0, 1]（fire, smoke），置信度阈值 0.8

```python
# 人员检测
results = self.person_model(frame, conf=0.8, classes=[0], verbose=False)
# 火焰检测
results = self.fire_model(frame, conf=0.8, classes=[0, 1], verbose=False)
```

`detect_person()` 和 `detect_fire()` 均返回 `(bool, annotated_frame)` — 是否检测到 + 带 Bounding Box 标注的画面。模型路径支持 config.yaml 配置，空值时 fallback 到 `src/models/fire_model.pt`。

### 4.2 FaceRecognizer（`src/core/face_recognizer.py`）

基于 OpenCV LBPH（Local Binary Patterns Histograms）算法：

```
初始化：
  1. 创建 Haar Cascade 人脸检测器（haarcascade_frontalface_default.xml）
  2. 创建 LBPHFaceRecognizer（threshold=tolerance）
  3. 从 faces_dir 加载家庭成员照片
     ├─ 每张照片 → Haar检测人脸 → 取最大人脸ROI → resize(100x100)
     ├─ 收集所有样本 → recognizer.train(samples, labels)
     └─ 记录姓名列表 self._labels

is_stranger(frame)：
  1. BGR → 灰度
  2. Haar Cascade 检测人脸位置
     ├─ 无人脸 → return False（保守：无人脸不报警）
  3. 未训练 → return True（无家庭成员库，所有人都是陌生人）
  4. 对每个检测到的人脸：
     ├─ resize(100x100) → recognizer.predict()
     ├─ 置信度 < tolerance → 家庭成员 → return False
  5. 所有人脸都不匹配 → return True（陌生人）
```

容忍度默认 80.0（LBPH的confidence值），越小越严格。家庭成员照片目录 `src/models/family_faces/`，每人放1-3张正面照。

### 4.3 AlarmManager（`src/core/alarm_manager.py`）

防抖去重机制——冷却期计时器：

```python
def should_trigger_alarm(self, event_type: str) -> bool:
    current_time = time.time()
    time_since_last = current_time - self.last_alarm_time[event_type]
    if time_since_last > self.cooldown:    # 超过冷却期（默认10秒）
        self.last_alarm_time[event_type] = current_time
        return True                        # 触发新报警
    return False                           # 冷却期内，不更新计时器，抑制重复
```

关键设计：冷却期内**不重置计时器**，计时器只在成功触发报警时才更新。这确保了"从上次报警时刻起算10秒"而非"从上次检测时刻起算"。

`last_alarm_time` 是 `Dict[str, float]`，fire 和 person 两种事件类型**独立计时**。

### 4.4 DatabaseManager（`src/core/db_manager.py`）

SQLite 嵌入式数据库，零配置：

```sql
CREATE TABLE IF NOT EXISTS alarms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    event_type TEXT NOT NULL,     -- "fire" 或 "person"
    timestamp TEXT NOT NULL,      -- "2026-06-23 15:30:00" 格式
    image_path TEXT NOT NULL      -- 截图文件路径
)
```

- `insert_alarm(event_type, image_path)` → 写入记录，返回自增ID
- `get_recent_alarms(limit=50)` → 按 ID 降序查询最近记录
- `get_alarms_by_type(event_type)` → 按类型筛选
- `delete_alarm(alarm_id)` / `clear_all()` → 删除/清空
- 连接使用 `check_same_thread=False`，允许 GUI 主线程和检测循环共享连接
- 所有操作有 try/except 保护，失败时记录日志并返回安全默认值

### 4.5 ConfigReader（`src/core/config.py`）

从 `config.yaml` 加载配置，内置默认值回退：

```python
_DEFAULT_CONFIG = {
    "monitor": {"person_start": "00:00", "person_end": "23:59"},
    "alarm": {"cooldown_seconds": 10},
    "detection": {"person_conf": 0.8, "fire_conf": 0.8, "fire_classes": [0, 1]},
    "camera": {"device_id": 0, "width": 640, "height": 480},
    "recognition": {"faces_dir": "src/models/family_faces", "tolerance": 80.0},
    "gui": {"loop_delay_ms": 30, "fps_interval": 1.0},
    "logging": {"level": "INFO", "file": "security_monitor.log"},
}
```

递归合并：config.yaml 的值覆盖默认值，嵌套字典逐层合并而非整体替换。`get(section, key, default)` 提供三层回退：配置值 → 默认值 → 参数默认值。

### 4.6 GUI 组件

**SecurityApp**（`src/gui/app.py`）— 主控制器，管理检测循环和界面交互：

- `PanedWindow` 左右分栏布局：左侧视频+状态栏，右侧历史列表+按钮
- `_detection_loop()`：30ms间隔的 tkinter.after 循环
- `_process_frame()`：单帧检测+判断+报警+界面更新
- `_save_alarm()`：截图保存+数据库写入+状态栏更新+历史列表刷新
- 摄像头断连自动重试（每秒重试一次）

**VideoFeedPanel**（`src/gui/video_panel.py`）— 视频显示面板：
- `update_frame(frame)`：OpenCV BGR → RGB → PIL Image → tkinter PhotoImage
- `show_placeholder()`：灰色"No Signal"占位图
- 目标尺寸 640×480，自动缩放

**StatusPanel**（`src/gui/status_panel.py`）— 状态指示栏：
- 三行布局：布防模式+火警+人脸状态 / FPS / 最近报警 / 摄像头状态
- `update_person_status(is_night, has_person, is_stranger)` 四种状态：
  - 陌生人→红色"INTRUSION!" / 家人→绿色"Family" / 布防中无→灰色 / 非布防→灰色
- `update_fire_status(fire_detected)`：FIRE ALERT!(红) / Clear(绿)

**HistoryPanel**（`src/gui/history_panel.py`）— 报警历史列表：
- `Treeview` 四列：ID / Type / Time / Screenshot
- fire 行粉色底色、person 行橙色底色
- 双击行 → 打开截图文件
- Refresh / View Image / Delete / Clear All / Exit 按钮

**utils.py** — 工具函数：
- `frame_to_photoimage()`：OpenCV帧→tkinter可显示图像的桥梁
- `create_placeholder()`：生成灰色"No Signal"占位图

### 4.7 CLI模式（`src/main.py`）

纯 OpenCV 窗口，无 tkinter，适合调试和低资源环境：

- `while True` 循环持续读帧
- `cv2.imshow("Home Security Camera", display_frame)` 显示画面
- `cv2.waitKey(1) & 0xFF == ord('q')` 按 q 退出
- 同样的检测流程：布防时段→人员检测→陌生人判断→火焰检测→防抖→截图→写库

## 五、模型训练

**训练脚本**：`training/train_fire.py`

```
YOLOv8n (COCO预训练) → 迁移学习 → fire_model.pt

数据集：DFire (Kaggle, 21,000+张, 2类: fire/smoke)
训练参数：epochs=50, imgsz=640, batch=16, device=cuda:0, patience=20, workers=0
训练环境：RTX 4060 Laptop GPU, PyTorch 2.6.0+cu124
训练结果：mAP50=0.765, mAP50-95=0.446
```

`workers=0` 是 Windows 平台的必要设置，避免 DataLoader 多进程崩溃。

**部署脚本**：`training/export_model.py`

```
runs/detect/training/runs/fire_smoke/weights/best.pt → src/models/fire_model.pt
```

部署后自动验证模型类别：`{0: 'fire', 1: 'smoke'}`。

## 六、配置文件（`config.yaml`）

```yaml
monitor:
  person_start: "00:00"    # 人员检测时段（默认全天，可改为23:00-06:00）
  person_end: "23:59"

alarm:
  cooldown_seconds: 10     # 报警冷却时间

detection:
  person_conf: 0.8         # 人员检测置信度阈值
  person_classes: [0]       # COCO class 0 = person
  fire_conf: 0.8           # 火焰检测置信度阈值
  fire_classes: [0, 1]      # 自训练模型: 0=fire, 1=smoke
  fire_model_path: ""       # 空=使用src/models/fire_model.pt

camera:
  device_id: 0             # 摄像头编号
  width: 640
  height: 480

recognition:
  faces_dir: "src/models/family_faces"  # 家庭成员照片

  loop_delay_ms: 30        # 检测循环间隔
  fps_interval: 1.0        # FPS刷新间隔
  min_width: 1024
  min_height: 700

logging:
  level: "INFO"
  file: "security_monitor.log"
```

## 八、课题要求对照

| 课题原文 | 实现对应 |
|----------|----------|
| "基于家庭安装的摄像头形成动态视频" | `cv2.VideoCapture` 实时采集，GUI/CLI 双模式显示 |
| "结合AI分析" | YOLOv8 推理：人员检测(COCO预训练) + 火焰检测(自训练) |
| "训练算法" | `training/train_fire.py` DFire数据集迁移学习，mAP50=0.765 |
| "对烟雾及火焰检测，发现就标注报警" | `detect_fire()` → Bounding Box标注 + AlarmManager防抖 + 截图 + 写库 |
| "在特定时段对进入人员进行检测，发现陌生人员闯入就标注报警" | `detect_person()` → `is_stranger()` LBPH比对 → 仅陌生人触发报警 |
| "重复的报警要过滤合并" | `AlarmManager` 10秒冷却期，独立计时，冷却期内不重置计时器 |

## 九、数据流全景

```
摄像头 ──→ 视频帧(frame)
              │
              ├── [布防时段?] ──→ YOLO人员检测 ──→ 有person?
              │                                      │
              │                                  FaceRecognizer.is_stranger()
              │                                      │
              │                          陌生人 ──→ AlarmManager ──→ 截图 ──→ DB
              │                          家人   ──→ 不报警，显示"Family"
              │
              ├── YOLO火焰检测 ──→ 有fire?
              │                      │
              │                  AlarmManager ──→ 截图 ──→ DB
              │
              └── 合成显示帧 ──→ GUI更新
                  (时间戳 + 布防状态 + 检测标注框)
```

# Home Security Monitor 项目计划

## 1、项目概述

本项目为软件工程课程设计项目，目标是开发一套基于 YOLO 深度学习的 AI 家庭安防监控系统，实现 24 小时火焰/烟雾检测与特定时段人员闯入检测。

## 2、项目范围

### 包含

- 实时视频流获取与显示
- 全天候火焰/烟雾 AI 检测与报警
- 特定时段人员闯入 AI 检测与报警
- 报警防抖去重机制
- 报警截图自动保存
- 报警历史记录存储、查询、删除
- GUI 图形界面 + CLI 命令行
- 配置文件管理（config.yaml）
- 日志系统

### 不包含

- 云存储与远程推送
- 家庭成员面部识别
- 多摄像头同时接入
- 移动端 APP

## 6、风险管理

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| YOLO 推理速度不足 | 中 | 高 | 使用轻量级 yolov8n 模型；精简检测类别 |
| 火焰模型误报率高 | 高 | 中 | 提高置信度阈值至 0.8；限制检测类别 |
| 摄像头兼容性问题 | 低 | 中 | 提供重试机制和占位图 |
| 团队协作冲突 | 低 | 低 | Git 分支管理，明确分工 |

## 7、质量标准

- 代码覆盖率：核心模块（AlarmManager、DatabaseManager）> 80%
- 视频帧率：≥ 15 FPS
- 报警延迟：≤ 2 秒
- GUI 响应时间：≤ 500ms
- 系统连续运行：24 小时无崩溃
